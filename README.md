# Blogcomnodeemongodb

> Blog completo com Node.js, Express e MongoDB. Possui autenticacao local com Passport.js, upload de imagens com Multer e templates Mustache.

## Stack

- Express.js
- MongoDB / Mongoose

## Prerequisitos

- Node.js v14+
- MongoDB

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/blogcomnodeemongodb.git
cd blogcomnodeemongodb

# Instale as dependencias
npm install

# Inicie a aplicacao
npm start
```
